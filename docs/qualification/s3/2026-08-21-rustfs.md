# RustFS Provider Qualification - 2026-08-21

## Result

The complete Sluice provider contract passed against an isolated RustFS
1.0.0-beta.9 service. RustFS is an independent S3 implementation, so this run
satisfies the third-provider portion of the Phase 1 matrix. It does not replace
the required AWS S3 run.

## Environment

| Item | Evidence |
| --- | --- |
| Host | macOS 26.5.2, Darwin arm64 kernel |
| Go | `go1.27.0 darwin/amd64` |
| RustFS | `1.0.0-beta.9` |
| Image | `rustfs/rustfs@sha256:f75d0bca6ca322c4e59f7125f73dd9ab709b22f71396a42c95bce7f74c99e53b` |
| Container platform | Linux arm64 |
| Endpoint | Loopback HTTP on an isolated test port |
| Bucket | Temporary bucket with versioning enabled |
| Adapter | AWS SDK v2 S3 `v1.107.3`; transfermanager `v0.3.15` |

RustFS's upstream
[S3 compatibility matrix](https://github.com/rustfs/rustfs/blob/main/docs/architecture/s3-compatibility-matrix.md)
records the relevant conditional-write, multipart, range, checksum, and
versioning surfaces. Sluice did not rely on that claim: it executed its own
black-box contract against the pinned artifact.

## Observed contract

```text
provider=RustFS 1.0.0-beta.9 capabilities={ConditionalWrites:true RangeDownloads:true MultipartUploads:true ObjectVersioning:true ChecksumSHA256:true}

--- PASS: TestProviderQualification (0.23s)
PASS
ok   github.com/d31ma/sluice/internal/objectstore/s3 1.001s
```

The run covered paged listing, create-only and ETag compare-and-swap,
automatic multipart upload, full and ranged download, SHA-256 verification,
and exact version deletion. Listing versions after the test returned neither
versions nor delete markers.

The temporary bucket was deleted. The named container and its anonymous data
volume were stopped and removed. The credentials existed only as synthetic,
process-scoped qualification values.

## Qualification boundary

RustFS was a beta release on the evidence date. This record proves compatibility
with the exact pinned artifact; it is not a production-provider recommendation
or a general claim about later RustFS releases.
