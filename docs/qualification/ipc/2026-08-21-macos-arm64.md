# Agent IPC Qualification: macOS arm64, 2026-08-21

## Result

The Phase 1 agent-bridge contract passed on the named host. A real Tachyon
26.33.02 server invoked the compiled `sluice-yon` executable, which forwarded
the request over the bounded authenticated IPC protocol to a persistent local
handler. Tachyon was stopped, restarted on the same port, and completed the
same bridge again.

This evidence qualifies the bridge on this host only. Windows and Linux native
execution remain separate gates.

## Qualified contract

- IPC listens only on an explicit loopback address.
- Every agent start creates a fresh 256-bit session capability.
- The private mode-0600 descriptor separates IPC authority from the local API
  bearer credential.
- Agent frames are newline-delimited JSON, protocol-versioned, and bounded to
  1 MiB requests and 4 MiB responses.
- Authorization and idempotency headers survive the Yon-to-agent bridge.
- Wrong session capabilities, protocol mismatches, oversized requests, and an
  unavailable agent fail closed with stable classifications.
- Connection admission is bounded. Shutdown prevents new worker admission,
  cancels active handler contexts, releases a saturated accept loop, and waits
  for admitted workers to finish.
- The persistent agent owns state startup and shutdown; it publishes the
  descriptor only after state starts and removes its own descriptor on clean
  shutdown.
- Duplicate mutations are replayed only when a supplied idempotency store has
  recorded the result.
- The production `sluice-agent` command currently supplies a rejecting store,
  so mutation requests fail with `state_unavailable` before application code
  runs. This remains safe across restart until the Fylo-backed idempotency
  repository is implemented; process memory is not presented as durable.
- Tachyon registration passes the session descriptor as a direct argument
  vector. No shell interprets the executable or its arguments.

## Remaining integration gates

- Replace `agent.RejectingIdempotencyStore` in the production command with a
  Fylo-backed implementation before enabling any mutation route.
- Run the complete `sluice-agent` executable with the real Fylo supervisor and
  real Tachyon server in one black-box process test. The two process contracts
  are qualified independently today, but not yet as one four-process chain.
- Repeat the contract and race suites natively on Windows and Linux.
- The production topology uses authenticated loopback TCP for its portable
  Phase 1 contract. A later ADR may promote Unix-domain sockets and Windows
  named pipes without changing the versioned envelope.
