# Linux Desktop Qualification Record: 2026-08-21

## Result

The Linux arm64 Fyne executable, XDG state/autostart contracts, bundle-relative
runtime topology, and bounded native smoke lifecycle passed in an isolated
Linux arm64 Docker environment with Xvfb and a private D-Bus session.

The test is deliberately classified as headless partial evidence. The D-Bus
session had no status-notifier watcher or notification service, so Fyne logged
failed registrations for those two integrations. No tray pixel, menu action,
notification delivery, screen-reader behavior, or real-login launch is claimed.

## Evidence

- Source: `83b47eefc634a22534abb0e77e97abd17b829ecf`.
- Native environment: LinuxKit 7.0.12 aarch64 with Debian Trixie/glibc 2.41.
- Package: relocatable unsigned `Sluice.AppDir` with a validated freedesktop
  desktop entry and bundle-relative Sluice/Tachyon/Fylo executables.
- Lifecycle: two complete starts on one isolated state root, authenticated
  health before Fyne, native Unix IPC, stable API token, and clean reverse-order
  shutdown without surviving children.
- Autostart: native Linux race-enabled XDG contract tests passed as an
  unprivileged user. The test did not log into a graphical desktop session.

Reproduction and exact image/runtime identities are recorded in
`../runtime/2026-08-21-linux-arm64-container.md`.
